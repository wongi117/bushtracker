# 🚀 BushTrack Vercel Deployment Guide

## Quick Deploy (One-Command)

### Option 1: PowerShell Script (Windows)
```powershell
# Run the deployment script
.\deploy-vercel.ps1
```

### Option 2: Bash Script (Mac/Linux)
```bash
# Make script executable
chmod +x deploy-vercel.sh

# Run deployment
./deploy-vercel.sh
```

### Option 3: Manual Commands
```bash
# 1. Install Vercel CLI (if not already)
npm install -g vercel

# 2. Login to Vercel (first time only)
vercel login

# 3. Build Flutter web app
flutter build web --release

# 4. Deploy to Vercel
vercel --prod
```

## 📋 Prerequisites

Before deploying, ensure you have:

1. ✅ **Flutter SDK** installed
   - Download: https://flutter.dev/docs/get-started/install
   - Verify: `flutter doctor`

2. ✅ **Node.js** installed (for Vercel CLI)
   - Download: https://nodejs.org/
   - Verify: `node --version`

3. ✅ **Vercel CLI** installed
   - Install: `npm install -g vercel`
   - Login: `vercel login`

4. ✅ **Vercel Account**
   - Sign up: https://vercel.com/signup
   - Can use GitHub/Google/email

## 🔧 Using Your Vercel Token

A Vercel Personal Access Token is needed. Never write it into this file or any other tracked file — a live one was committed here once and GitHub's push protection caught it. Keep it in the environment only.

### Method 1: Environment Variable (Recommended)
```bash
# Windows PowerShell
$env:VERCEL_TOKEN="YOUR_VERCEL_TOKEN"
vercel --token $env:VERCEL_TOKEN

# Mac/Linux
export VERCEL_TOKEN="YOUR_VERCEL_TOKEN"
vercel --token $VERCEL_TOKEN
```

### Method 2: Vercel CLI Login (One-time)
```bash
# This will cache your credentials
vercel login
# Follow the browser authentication
```

### Method 3: GitHub Actions (Auto-deploy)
Set up these secrets in your GitHub repository:

1. Go to: `Settings > Secrets and variables > Actions`
2. Add these secrets:
   - `VERCEL_TOKEN`: Your token
   - `VERCEL_ORG_ID`: Your Vercel organization ID (get from .vercel/project.json after first deploy)
   - `VERCEL_PROJECT_ID`: Your Vercel project ID (get from .vercel/project.json after first deploy)

## 🌐 Deployment Configuration

### Current Configuration

**`vercel.json`:**
```json
{
  "version": 2,
  "name": "bush-track",
  "builds": [
    {
      "src": "build/web/**/*",
      "use": "@vercel/static"
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/index.html"
    }
  ]
}
```

This configures:
- ✅ Single Page Application (SPA) routing
- ✅ Static file serving from `build/web/`
- ✅ Proper caching headers
- ✅ All routes serve `index.html` (Flutter requirement)

## 🚀 Deployment Steps

### Step 1: Build the Flutter Web App

```bash
cd "bush track/bush_track"

# Get dependencies
flutter pub get

# Build for production
flutter build web --release
```

**Output:** Creates `build/web/` folder with:
- `index.html` - Entry point
- `main.dart.js` - Compiled Dart code
- Assets, fonts, images

### Step 2: Deploy to Vercel

```bash
# If not logged in
vercel login

# Deploy (first time - interactive setup)
vercel

# Follow prompts:
# ? Set up and deploy "bush_track"? [Y/n] Y
# ? Which scope? [Your username]
# ? Link to existing project? [n]
# ? What's your project name? [bush-track]
# ? In which directory is your code located? [./]

# For subsequent deploys (production)
vercel --prod
```

### Step 3: Get Project Info for GitHub Actions

After first deploy, Vercel creates `.vercel/project.json`:

```json
{
  "orgId": "your-org-id",
  "projectId": "your-project-id"
}
```

Add these to GitHub Secrets for automatic deployment.

## 🔄 Automatic Deployment (GitHub Actions)

### Setup Steps:

1. **Push to GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/bush-track.git
   git push -u origin main
   ```

2. **Configure Secrets** (in GitHub)
   - Go to: `Settings > Secrets and variables > Actions`
   - Add `VERCEL_TOKEN`: Your personal access token

3. **First Manual Deploy** (to get project IDs)
   ```bash
   vercel
   ```
   
4. **Add Project Secrets**
   - Copy `orgId` from `.vercel/project.json` → `VERCEL_ORG_ID`
   - Copy `projectId` from `.vercel/project.json` → `VERCEL_PROJECT_ID`

5. **Future Pushes Auto-Deploy!**
   Every push to `main` branch will automatically deploy to Vercel.

## ⚠️ Important Notes

### Web Limitations
Some Flutter plugins don't work on web:
- ✅ **Working**: GPS (with browser permission), AI, Maps, Mesh simulation
- ❌ **Not Working**: Bluetooth mesh (real), Camera (may vary), some sensors

### Environment Variables
If your app needs API keys (like OpenRouter AI), add them to Vercel:

```bash
vercel env add OPENROUTER_API_KEY
```

Or in dashboard: `Project Settings > Environment Variables`

### Custom Domain
```bash
# Add custom domain
vercel domains add bushtrack.yourdomain.com
```

Or in Vercel Dashboard: `Project Settings > Domains`

## 🆘 Troubleshooting

### Issue: "Flutter not found"
**Solution:** 
- Install Flutter: https://flutter.dev/docs/get-started/install
- Add to PATH
- Run: `flutter doctor`

### Issue: "Build fails with errors"
**Solution:**
```bash
# Clean and rebuild
flutter clean
flutter pub get
flutter build web --release
```

### Issue: "Vercel login not working"
**Solution:**
- Use browser login: `vercel login`
- Or use token: `vercel --token YOUR_TOKEN`

### Issue: "404 errors on refresh"
**Solution:**
- Make sure `vercel.json` has SPA routing (already configured)
- Check `build/web/index.html` exists

### Issue: "Assets not loading"
**Solution:**
```bash
# Ensure all assets are in pubspec.yaml
flutter build web --release --web-renderer canvaskit
```
